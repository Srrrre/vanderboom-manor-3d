## 三维解释与推测

保留已有主屋、塔楼、附屋的外部尺寸，无需增加建筑进深。世界坐标正面为 +Z、左侧为 -X；底层地坪 y=0.45，二层 y=4.15。外墙厚 0.24m，主要内墙厚 0.16m，楼板厚约 0.18m。

底层主屋 x=-5.4..2.1、z=-3.8..4：南侧分成左厨房与右门厅；北侧为主客厅和楼梯厅。主客厅合并挑空绿厅与壁炉客厅的识别物件，是受外壳约束的压缩重建，不宣称它们在原作同属一个房间。西向直跑楼梯沿北墙布置，几何坡道从 (1.55,-2.82) 上到 (-3.8,-2.82)，宽1.35m，20级、升高3.7m。楼梯西端连接二层西侧栏廊，再向南到卧室门。这一朝向、级数、长度与连接方式服务于现有三维外壳和可行走路线，并非对原作楼梯布局的严格复刻。

塔楼底层作为东侧过厅，连接右附屋中的餐厅。这一方位连接没有直接截图证据。为保留附屋外观，不把餐厅正立面改成整面高拱窗；使用内侧拱形装饰表达截图语汇。二层卧室采用威廉房间的绿墙、长椅、立钟、桌和鸟笼，另加床作为未见视角的合理补全。

```text
             北 / -Z
底层   ┌──向西上楼的直跑楼梯──┐
       │ 壁炉 / 主客厅 / 扶手椅│
       ├───厨房────┬──门厅───┤──东过厅──餐厅（右附屋）
       │           │  正门   │
       └───────────┴───┬─────┘
                        前廊 / 前院 / +Z

二层   楼梯上端──西侧栏廊
                    │    挑空区域（有护栏）
                    ├ E 开门 → 威廉客房 / 卧室
                    └ 关闭的后续区域入口
```

绝对尺寸、楼梯朝向、压缩房间边界与家具摆位都是可调整推测。将图像可见要素与空间重建假设分开记录，避免把游戏画面的非物理透视当作测绘图。

## 最终实现与通行约束

- 楼梯从主厅转入的验证入口为 **x=1.48、z=-2.82**，此处脚底约 y=0.4984。它位于几何坡道起点稍西侧，避开东墙。南侧扶手从第三级开始，其下端 x=1.015，为身体半径 0.28m 的玩家留出转入空间；北侧扶手保持连续的登楼引导。
- 楼梯顶端先到栏廊 x≈-4.48、z=-2.82，再沿栏廊到 z=1.55，经 x=-3.7 的门进入卧室。楼梯连接处的楼板碰撞边缘后退 0.29m，避免身体先接触平台竖边；可见楼板和可站立表面的范围不缩小。
- 二层实体楼板只有西侧栏廊 x=-5.16..-3.8、z=-3.56..3.76，以及卧室及其门口连接 x=-3.85..1.86、z=-0.45..3.76。**没有用整块楼板封住主厅和北侧楼梯上方的挑空**；栏廊朝挑空侧设护栏，楼梯顶部横向入口保持可通行。
- 门厅圆桌、厨房桌椅和炉、主厅粉色扶手椅与白壁炉、餐厅长桌与竖琴、卧室长椅与立钟等，采用原创几何表达参考中的物件类别。物件尺寸、数量、具体位置和朝向按门扇摆动及通行净空重新布置，不表示截图提供了这些尺寸或空间关系。
- 卧室增加的床、过厅小几与简化半身像、餐具、花瓶及局部装饰是空间补全。餐厅的拱形语汇采用靠后墙的内饰拱框，正立面仍使用现有外壳窗洞；不会把参考中的连续高拱窗直接替换到附屋正面。
- 室内与外壳共用底层 y=0.45、二层 y=4.15；主屋顶内面 y=8.04，附屋餐厅顶内面 y=3.35，塔楼底层过厅顶内面 y=3.97。塔楼上部、书房、浴室和阁楼本阶段均不作为可探索房间。

本阶段的实现检查与浏览器记录见 [室内验收报告](interior-test-report.md)。上述坐标是本项目实现参数，不是原作的测绘数据。
门扇通行微调：正门叶宽由原占位模型的1.18m改为1.22m，实体入口洞宽1.32m；室内门洞在门叶外保留约7cm铰链侧净空，避免全开时门厚嵌入墙垛。主屋、塔楼和附屋的长宽高均未改变。
