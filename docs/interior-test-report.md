## 实测修复

1. 移除正门前旧实心墙与整块建筑碰撞，墙网格和碰撞共同按洞口拆分。
2. 楼梯最低端靠东墙，缩短南侧扶手末端，留出从主厅转入楼梯的身体净空。
3. 二楼平台竖面会提前碰到玩家半径，调整平台碰撞边缘以连续登上楼板；可见楼板与支撑范围保持完整。
4. 书房锁门原先埋在墙内，移至室内墙面前，并补充真实场景射线回归。
5. 增加铰链侧净空，避免全开门厚嵌入墙垛；门洞及门框宽度从同一门配置派生。
6. 门叶装饰同材质合批，每门33个Mesh降为4个，七门231降为28；保留动态铰链根节点和碰撞体。相同欢迎镜头首帧记录的绘制调用由693降到287，渲染三角面计数175,460；不将这一计数当作跨设备帧率保证。
