## 实测修复

新Aldous木地板最初与原塔楼天花顶、旧后墙顶共面，造成地面闪烁。通过真实网格上下射线复现后，调整旧天花视觉厚度、新地板视觉厚度及后墙开口底高；维持支撑与碰撞楼层不变。新增两项回归覆盖上方地面和下方天花，均通过。

独立抽查312个楼梯、平台及房间位置，其中263个可站立点未发现梁或屋檐侵入成人头部，最小结构净高约3.515m。此项采样不代表穷尽所有位置。

## 范围和限制

- 房间绝对方位和折返楼梯是同人可行走布局，非原作官方平面；详细依据见 [扩容与参考](aldous-expansion.md)。
- 未增加背包、剧情、跳跃、触屏控制或精细材质，书房、浴室及阁楼仍关闭。
- 未对所有键盘组合及不同实体显卡做穷尽测试；室内无实时点光源阴影。
- 原作图片未复制入项目，发布只含原创程序几何、代码、测试和文档。
