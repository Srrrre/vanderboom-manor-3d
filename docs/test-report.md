## 发现并修复

1. 新版 Vite 构建配置与 CSS 类型声明兼容问题。
2. Edge 自动化环境中 Esc 未原生解锁，新增显式回退，保留浏览器默认行为。
3. 暂停蒙层挡住工具栏点击。
4. 前廊顶面与可行走高度 0.035m 偏差。
5. 突出的门窗没有对应碰撞体；修复前后用真实网格射线回归。
6. 岩山碰撞圆过小；实际失败坐标通过后改为完整外接圆。
7. 方位图东西朝向镜像。
8. Three.js r186 已移除 PCFSoftShadowMap，改用受支持的 PCFShadowMap。

## 保留限制

Three.js 主分包约 548 KB（gzip 137 KB），会出现 Vite 的 500 KB 体积提醒；已独立分包，无额外大型运行依赖。树冠、芦苇和细碎岸石不设碰撞；大山体使用保守外接圆，部分山脚会提前阻挡。没有触屏控制、跳跃、室内、动态水面或油画后处理。

截图只能支持轮廓级重建；绝对尺度与侧背面仍是推测，不能宣称完成精确测绘式还原。
