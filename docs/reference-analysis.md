# 范德布姆庄园参考分析

已于 2026-10-08 实际查看用户提供的本机截图文件夹中的 `庄园全貌.jpg`、`正门.jpg`、`猎场.jpg`、`不知道哪的走廊.jpg`。原图仅在本机研究，不复制进项目或公开仓库。

## 有截图依据的结构

- 全貌不是对称城堡：左侧为两层长方主体，右侧为与主体相接的窄方塔；最右边为一层附屋。前廊覆盖主体和塔楼下方的连续正面。
- 全貌图大致像素范围：主体 x=562–750，塔楼 x=750–850，附屋 x=850–1017；地坪 y≈828，主体檐口 y≈551，主体屋脊 y≈455，塔楼檐口 y≈440，塔顶 y≈336。前廊左缘比上层主体略向左伸出。比例以这些轮廓为依据，不能把截图透视当作精确测绘。
- 主屋青灰色高坡屋顶，正面为宽坡面，单个阁楼窗；屋脊大致横向。塔顶为四面折线坡的近似法式帽顶，宽檐、上部小平台、正面居中的拱冠老虎窗，不是尖锥或普通平顶。塔顶约为主体檐高的 1.75 倍。
- 正面底层：深灰蓝单门居中，两侧各一扇白框多格窗。近景窗为 3 列，上扇 2 排、下扇 3 排；门有上亮窗、主面板、下部双嵌板及右侧门把手。
- 四根主要前廊立柱，方形基座、细长竖向线脚和带圆形饰盘的方形柱头；平直横梁，青灰色浅坡顶，薄台基及入口台阶。浅暖灰色水平挂板墙、白色窗套及窗台。
- 上层正面共三扇细长窗：左主体两扇、塔楼一扇。主屋坡面一个阁楼窗；塔楼帽顶一个较高老虎窗。
- 右附屋为低矮棕灰木墙、红褐色坡屋顶，正面两扇窗；为忠于截图保留其红褐色屋顶，与主屋青灰色形成区分。
- 草地前院开阔，左前方有马车。远景左侧为湖与针叶树林，右后方为明显岩山，地势起伏。走廊图显示白柱廊外可见草地、山、树林、湖、溪流/桥和远处小建筑。

## 可调整的尺度与推测

以米为单位：连续主立面宽约 10.8，主体深 7.8，双层墙体高 8.2；方塔宽约 3.3、深 4.2、墙高 11.6、帽顶最高约 15.2；附屋宽 5.2、墙高 3.5；门高 2.65，漫游眼高 1.68。图中人物和夸张艺术透视只能辅助校准，以上均非官方尺寸。

建筑进深、背面窗户、后门及侧面分布无直接依据；采用克制的重复窗套和封闭外墙补全。主屋后坡、塔楼四面帽顶和附屋双坡均为根据正面轮廓推定的三维解释。入口薄台基细化为三层低台阶以适配步行。

走廊究竟位于哪一侧无法确定，不另造大型翼楼；用正面可通行前廊表达柱廊语汇。湖在场景左后方、岩山右后方，符合全貌视觉关系；确切距离、岸线、环屋道路、树木/岩石坐标均为漫游需求下的补全。马车仅为几何占位，不复原人物或马匹。室内截图不用于推导未经证实的外部体块，本阶段不建室内。

## 建模边界

所有建筑使用有体积的网格、坡屋顶、窗框、墙体和柱体；没有截图贴片。保留浅墙、青灰屋顶、林湖岩山的识别要素。材质、地形、场景根节点与建筑参数分离，后续可替换 GLB。油画后处理、精细植被、复杂水面、室内均留待后续。
