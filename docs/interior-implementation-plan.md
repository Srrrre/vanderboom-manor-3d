# 室内贯通实施计划

用户明确授权直接实施、测试、推送与部署，不重复设置设计审批环节。沿用已读取的 brainstorming / writing-plans / verification 工作流程。

1. 实际阅读16张参考，记录图像证据、平面推测与无外壳扩大的布局。
2. 扩展 Collider 高度区间及 OBB；建立 WalkSurface 与可站立高度选择，以小步解决水平碰撞、头顶净空及跨层限制。
3. 将实心建筑替换为带真实门窗洞的有厚度墙体；保留坡顶、帽顶、前廊与原立面窗位。构件工具支持开洞和合批。
4. 构建底层房间/楼梯、上层西栏廊/卧室与楼板开口；家具和栏杆加入有高度的碰撞。
5. 动态门独立管理：OBB随动画更新，距离+视线交互，扫掠检测阻止夹人，E键提示。
6. 接入玩家、房间提示、灯光/雾过渡与小地图；保留室外控制和重置。
7. 单元/场景路线测试、真实浏览器从院内进门到二层再出门、图像审查、独立代码审查及修复。
8. 更新README与验收记录，检查敏感素材，推送main、核验Pages并线上实测。

模块分工：controls负责纯运动与输入；interactions负责动态门；world/manor保留外观并生成壳体；world/interior负责房间/家具/楼梯；layout集中尺寸、门与楼板；main只编排。

关键回归：一楼不吸到二楼；楼梯斜向跑动不穿栏杆；楼板开口有保护；门关闭时不可穿越、旋转中不夹人；暂停时不触发E；室外湖岸/岩石/失焦行为不退化。
