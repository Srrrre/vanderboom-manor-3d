# Aldous 房间与门厅扩容

## 本次目标

用户要求补上“主厅侧门 → 走廊 → 小楼梯 → Aldous 房间”，并让进门后的空间稍大。沿用鼠标锁定、E键互动门和分层碰撞，不增加剧情系统。旧空间、厨房、餐厅、威廉房间和室外仍需能往返。

## 图像与推测

本次重新实际查看：阿道斯房间、adouls房间右边、走廊右边楼梯上去的场景阿道斯房间、阁楼，adouls门前、主场景沙发右边那个门的场景走廊。

- 房内蓝灰墙、深色斜木梁、粉棕多格窗、三屉柜与闹钟、奶油色圆桌与碗、木框白色竖褶屏帘、挂衣架与衣帽伞均有截图依据。
- 屏帘后是否为床及具体床型不能从图中确认，不能把补全的床体当作截图事实。
- 门前蓝墙、木门牌、杯柜、梁架和矩形舱口有依据。
- 侧走廊有左侧闭门、尽头短梯和高窗、右侧另一段上行楼梯。完整楼层高度与各视角的绝对方位不明确。
- 为容纳合理坡度，采用两段短梯及转向平台，升高3.7m。把房间安排在塔楼二层并向后延伸、把楼梯湾置于塔楼后部均为同人空间推测。

所有碰撞与可站立表面应跟随尺寸更新，不能用修改视野角度代替实际扩容。门厅扩大时同步扩大主厅，不挤占主厅走路面积。
